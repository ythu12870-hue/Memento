# Template music folders

There are 25 template folders, each with five music slots. Add MP3 files named `track-1.mp3` through `track-5.mp3` in the matching folder. In VS Code use `app/page.tsx` to change the visible option names in `musicSlots`, and the template IDs below match the folder names.

Use music you have permission to distribute. This starter does not include copyrighted/trending music files or automatically discover songs; you supply the files.

Template folders: anniversary-surprise, love-letter, long-distance-love, first-meet, just-because-love, best-friend, friendship-timeline, inside-jokes, thank-you-friend, farewell-friend, mom-thank-you, dad-thank-you, family-memories, grandparents, family-thank-you, birthday-surprise, graduation, new-job, wedding-wishes, new-home, you-can-do-it, future-self, new-beginnings, proud-of-you, self-love
