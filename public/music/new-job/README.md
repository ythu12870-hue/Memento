# Music for A new chapter begins

Add up to five audio files in this folder using these exact filenames:

- `track-1.mp3`
- `track-2.mp3`
- `track-3.mp3`
- `track-4.mp3`
- `track-5.mp3`

The creator's Step 3 music slots look for these exact paths. The exported HTML embeds the selected track so it can play when the HTML file is opened separately. Use music you have permission to use.
